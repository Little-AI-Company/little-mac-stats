## Icon prompt

Use case: logo-brand. Asset type: production macOS application icon, square 1024x1024. Create an original minimal monochrome icon for 'Mac Stats', a tiny native CPU monitor. Black square edge-to-edge background with an elegant centered white mark made of three precise vertical rectangular meter bars, left short, middle tall, right medium, joined conceptually by exact consistent spacing. The mark occupies the central 56 percent of the image, extremely crisp geometric edges, flat pure black and white, no text, no gradients, no shadows, no texture, no rounded outer square (macOS provides its own icon treatment), no battery outline, no circuit details, no brand logos. A severe Swiss modernist software identity, restraint and precision like minimalist developer brands but an original meter symbol. Deliver one icon only.

## Repository header prompt

Use case: ads-marketing. Asset type: GitHub repository header, wide landscape 3:1 aspect ratio, approximately 1800x600. Brand: Mac Stats, a small native macOS CPU utility. Create an extremely restrained Swiss modernist monochrome software banner. Pure black background. Left third: large crisp white geometric icon of three vertical rectangular meter bars with equal widths and even spacing, all aligned at bottom: left short, center tall, right medium. Right two thirds: large white clean modern sans-serif headline exactly 'Mac Stats'; beneath it smaller white simple sans-serif sentence exactly 'Know what is using your Mac.' Plenty of negative space, carefully aligned optical spacing. Flat black and white only, no gradients, no texture, no glowing, no cards, no pills, no battery shape, no decorative UI, no additional text, no watermark, no existing company logos. Quiet, precise, professional original identity inspired by minimal developer tooling branding.
